# Outputs Directory

Generated artifacts are saved here after running `src/train.py`.

| File | Description |
|---|---|
| `best_model.pkl` | Serialised best model (joblib) |
| `scaler.pkl` | Fitted StandardScaler |
| `label_encoder.pkl` | Fitted LabelEncoder |
| `selected_features.pkl` | List of selected feature names |
| `feature_importance.csv` | Feature importance scores table |
| `model_results.csv` | All model metrics comparison |
| `*.png` | All EDA and evaluation plots |
